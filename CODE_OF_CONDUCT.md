# Code of conduct

Embrasure Flow adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone participating in this project's
issues, pull requests, discussions and other project spaces, and to people
representing the project elsewhere.

In short: be respectful and constructive, assume good intent, and focus
criticism on ideas and code rather than people. Harassment, personal attacks
and discriminatory language are not acceptable.

## Reporting

Report unacceptable behavior privately to the maintainers at
**CONDUCT_CONTACT_EMAIL**. Reports are handled confidentially. The maintainers
will review each report and respond as the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
describe, from a private warning up to a permanent ban.

Security vulnerabilities are reported separately; see [SECURITY.md](SECURITY.md).
